# Участие в разработке

Спасибо за интерес к H9 Cluster. Проект принимает исправления, улучшения
интерфейса, документации и новые темы.

## Перед началом

1. Создайте Issue либо обсудите заметное изменение в Discussions.
2. Не работайте с головным устройством во время движения автомобиля.
3. Не публикуйте VIN, координаты, пароли, ключи подписи, заводские APK,
   декомпилированный код и необработанные диагностические материалы.
4. Используйте только read-only источники автомобильных данных. Добавление
   команд управления автомобилем не принимается.

## Сборка

Рекомендуемый воспроизводимый способ:

```bash
docker build --platform linux/amd64 -t h9-cluster-build .
docker run --rm --platform linux/amd64 \
  -v "$PWD:/workspace" -w /workspace \
  h9-cluster-build
```

Локальная сборка требует JDK 17 и Android SDK 35:

```bash
./gradlew assembleDebug lint
```

## Pull Request

- создавайте отдельную ветку для каждого изменения;
- объясняйте назначение и способ проверки;
- прикладывайте снимки для визуальных изменений;
- сохраняйте системные зоны индикаторов и центральную область карты;
- убедитесь, что GitHub Actions завершился успешно.

Отправляя вклад, вы подтверждаете право публиковать его и соглашаетесь на
распространение вклада по лицензии проекта
[PolyForm Noncommercial 1.0.0](LICENSE). Сторонние материалы должны иметь
отдельно указанную совместимую лицензию.
