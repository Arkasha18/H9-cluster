# Политика безопасности

## Поддерживаемые версии

Исправления безопасности выпускаются для актуальной версии из раздела
[Releases](https://github.com/Arkasha18/H9-cluster/releases).

| Версия | Поддержка |
| --- | --- |
| 9.x | Да |
| Более ранние версии | Нет |

## Как сообщить об уязвимости

Используйте
[Private vulnerability reporting](https://github.com/Arkasha18/H9-cluster/security/advisories/new).
Не создавайте публичный Issue до согласованного раскрытия проблемы.

В отчёте укажите:

- затронутую версию и компонент;
- безопасные шаги воспроизведения;
- возможное влияние;
- предлагаемый способ исправления, если он известен.

Не прикладывайте VIN, координаты, ключи, пароли, заводские APK, дампы памяти
или другие данные автомобиля и владельца. Если без чувствительного файла
невозможно подтвердить проблему, сначала опишите его состав без вложения.

## Границы проекта

H9 Cluster предназначен только для чтения штатных данных. Уязвимости,
позволяющие отправлять команды автомобилю, выполнять код с повышенными
привилегиями либо скрывать штатные предупреждения, считаются критическими.

Автор постарается подтвердить получение отчёта в течение семи дней, но
фиксированное время выпуска исправления не гарантируется.
