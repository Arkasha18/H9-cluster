# Автономный учебный Demo v8.0.7

Этот архив сохранён для прежних ссылок и изучения Canvas. Исходники приложения
относятся к v8.0.7; обновление документации не обновляет их до H9 Cluster 9.7.0.
Пример однодисплейный, с синтетическими показаниями и отдельным
`DashboardState`. Он не воспроизводит актуальный набор данных, настройку
скорости, сглаживание RPM и запуск на втором экране основного приложения.

**Для нового скина используйте build type `demo` актуальной `main`:**

```bash
git clone --single-branch --branch main https://github.com/Arkasha18/H9-cluster.git
cd H9-cluster
./gradlew :app:assembleDemo
```

На Windows вместо `./gradlew` используйте `./gradlew.bat`. Требования:
JDK 17, SDK 35, зависимости из актуального репозитория. Production-ключ для
Demo не нужен. Результат — `app/build/outputs/apk/demo/app-demo.apk`.

Полный процесс находится в `THREE_STAGE_WORKFLOW_RU.md`, подготовка окружения —
в `CODEX_LOCAL_SETUP_RU.md`. Их ссылки на исходники и инструменты относятся к
текущему репозиторию, а не к старым исходникам этого ZIP. Технический шаблон
1920×720 распространяется отдельным ZIP и входит в Forum Kit.

Ключевые правила нового дизайна:

- сначала полный состав показаний и паспорт координат, затем оформление;
- декор допустим под штатными полями по краям, сверху и справа внизу;
- нижние левые поля 06 свободны от добавленной графики с запасом 1 px;
- скин рисует только автоматический номер 1…8 при D в штатной зоне;
  буквы селектора, режим движения и штатные лампы не дублируются в production;
- исходник подложки 04 сохраняется; производная растушёвка проверяется отдельно;
- технические поля накладываются на макет для контроля, не вырезают из него части;
- цифры RPM стабилизируются отдельно от плавного движения шкалы;
- рабочий прозрачный слой и чёрный фон презентационного PNG разделены.

## Что находится в старом примере

Package: `net.adminrunet.h9clusterdemo`, launcher: `DashboardDemoActivity`.
`DashboardView`, `DashboardState`, `DashboardDataSource` и
`DemoDashboardDataSource` демонстрируют разделение отображения и тестовых данных.
Canvas рассчитан на 1920×720; автомобильных сервисов, CAN и второго дисплея нет.
Старый Classic — учебный фон, а не обязательная форма будущих скинов.

Для изучения старый проект можно собрать из корня распакованного архива:

```bash
./gradlew assembleDebug
```

Эта команда не переносит скин в основное приложение. Не устанавливайте
учебный APK вместо production-сборки с реальными показаниями.

Его результаты, сертификат и описание фона относятся только к тому примеру.
Это не отчёт о новой сборке и не подтверждение проверки на автомобиле.
