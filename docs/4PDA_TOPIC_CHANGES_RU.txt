Версия 9.5.0:

- добавлена встроенная проверка новых GitHub Releases: приложение показывает описание версии, загружает APK с прогрессом и запускает установку только после подтверждения пользователя;
- перед установкой обновления проверяются ожидаемое имя и HTTPS-адрес GitHub, имя пакета, увеличенный versionCode и совпадение сертификата подписи;
- штатный QNX-блок предупреждений теперь появляется поверх всех пользовательских скинов через откалиброванное прозрачное окно;
- часы, пробег, карточка ATF и наружная температура в Classic и Sport перенесены из зон штатных системных индикаторов;
- для Classic и Sport применена точная общая маска прозрачности 1920×720;
- цифры 20 и 0 на шкале Sport сохранены в отдельном прозрачном слое без чёрной подложки;
- в README добавлена галерея всех четырёх скинов с реальными снимками Display ID 2.
