# Иконка H9 Cluster

Выбранное оформление: белый знак H9 на графитовом фоне, янтарная шкала
с красным краем и короткая янтарная линия снизу. Буквы и цифра нарисованы
контурами и не зависят от установленных шрифтов.

![Иконка H9 Cluster](images/h9-cluster-icon-192.png)

## Файлы

| Назначение | Файл |
| --- | --- |
| Векторный исходник | [h9-cluster-icon.svg](images/h9-cluster-icon.svg) |
| Иконка для 4PDA и README, 192×192 | [h9-cluster-icon-192.png](images/h9-cluster-icon-192.png) |
| Иконка для публикаций, 512×512 | [h9-cluster-icon-512.png](images/h9-cluster-icon-512.png) |
| Иконка Android | [ic_dashboard.xml](../app/src/main/res/drawable/ic_dashboard.xml) |
| Значок служебного уведомления | [ic_dashboard_notification.xml](../app/src/main/res/drawable/ic_dashboard_notification.xml) |

AndroidManifest использует `@drawable/ic_dashboard` для меню приложений.
Все варианты сборки используют общий ресурс. Отдельный одноцветный значок
уведомления содержит H9 и дугу без подложки и мелких делений: Android
применяет к нему системный цвет, сохраняя прозрачный фон.

При изменении оформления синхронно обновляйте SVG, цветной Android-вектор
и оба PNG. При изменении контуров H9 обновляйте также значок уведомления.
Проверяйте читаемость при 32–48 пикселях и на светлом и тёмном фоне.

Публичное имя `h9-cluster-icon-192.png` сохранено для существующих ссылок
в документации. Уже загруженную на 4PDA картинку нужно заменить при
следующем обновлении темы; изменение файла в Git не обновляет вложение форума.
