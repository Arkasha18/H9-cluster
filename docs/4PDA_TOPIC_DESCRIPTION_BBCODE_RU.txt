H9 Cluster запускает отдельную приборную панель на втором дисплее автомобиля, сохраняя штатную карту и системные индикаторы головного устройства. Приложение не связано с Great Wall Motor или Haval и не является официальным программным обеспечением производителя.

Приложение читает основные автомобильные данные через штатный GWM Adapter. Для быстрого обновления тахометра используется read-only подписка FDBus, а при её недоступности автоматически применяется Binder. Температура масла АКПП читается по защищённому read-only SSH-подключению из уже обновляемого штатным ПО снимка TBOX. Команды управления автомобилем, запись параметров, CAN/UDS-команды и активные диагностические запросы не выполняются. Разрешение INTERNET используется только для внутреннего подключения к TBOX; к внешним интернет-сервисам приложение не обращается.

[spoiler="Установка через ADB"]
1. Подключите компьютер к головному устройству по ADB.
2. Установите APK с сохранением настроек:

[code]
adb install -r H9_Cluster_v9.2.0_adminrunet_release.apk
[/code]

3. Откройте настройки приложения:

[code]
adb shell am start -W -n net.adminrunet.h9cluster/.SettingsActivity
[/code]

4. Выберите тему и запустите её на дисплее 2.

Для ручного запуска панели:

[code]
adb shell am start --display 2 -W -n net.adminrunet.h9cluster/.PreviewActivity
[/code]
[/spoiler]
