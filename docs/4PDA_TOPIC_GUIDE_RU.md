# Публикация H9 Cluster на форуме 4PDA

Актуально на 27 июля 2026 года.

Готовый BBCode для большого поля «Описание программы» находится в
`4PDA_TOPIC_DESCRIPTION_BBCODE_RU.txt`.

Готовый текст для поля «Изменения» находится в
`4PDA_TOPIC_CHANGES_RU.txt`.

## Главное по правилам

Правила раздела:

https://4pda.to/forum/index.php?act=announce&f=751&st=250

Пример оформления автомобильного приложения:

https://4pda.to/forum/index.php?showtopic=672503

Перед публикацией выполнен поиск по разделу Android — Программы и его
подразделам:

- `H9 Cluster` — совпадений не найдено;
- `net.adminrunet.h9cluster` — совпадений не найдено.

Поиск рекомендуется повторить непосредственно перед созданием темы.

Новая тема создаётся не напрямую в подразделе «Транспорт и Путешествия»
(`f=751`), а через стандартный Мастер тем в корне «Android — Программы»:

https://4pda.to/forum/index.php?act=post&do=new_post&f=212

После создания тему может перенести в подходящий подраздел модератор.

Обязательные требования, которые относятся к H9 Cluster:

1. Название приложения должно точно соответствовать Manifest:
   `H9 Cluster`.
2. Нужно указать источник, авторство и имя пакета:
   - разработчик и релизер: `admin.ru.net`;
   - пакет: `net.adminrunet.h9cluster`;
   - источник: `https://github.com/Arkasha18/H9-cluster`.
3. Полноразмерные скриншоты нужно загрузить на форум и убрать под спойлер.
   Рендеры, промо-картинки, изображения с водяными знаками и пометками других
   сайтов использовать нельзя.
4. Рабочий APK нужно прикрепить к сообщению на сервере 4PDA. Одной ссылки на
   GitHub недостаточно.
5. Версия должна совпадать с Manifest: `9.2.0`.
6. Для APK нужно указать архитектуру: `arm64-v8a`.
7. В сообщении нельзя использовать разноцветный текст и увеличенный шрифт.
8. Для последующих обновлений нужно публиковать новый пост с APK, точной
   версией и списком изменений. Рекомендуется пользоваться инструментом
   «Релизер».

Заполняйте форму сверху вниз:

| Версия | `9.2.0` |
| Требуемая версия Android | выбрать `9 (API 28)` |
| Иконка приложения | загрузить `docs/images/h9-cluster-icon-192.png` |
| Скриншоты | загрузить `docs/images/h9-cluster-display-2.png` |

| Изменения | вставить содержимое `4PDA_TOPIC_CHANGES_RU.txt` |
| Разработчик | `admin.ru.net` |
| Домашняя страница | `https://github.com/Arkasha18/H9-cluster` |
| Google Play | оставить пустым |
| RuStore | оставить пустым |
| AppGallery | оставить пустым |
| F-Droid | оставить пустым |
| Имя пакета | `net.adminrunet.h9cluster` |
| YouTube | оставить пустым |
| RUTUBE | оставить пустым |
| Файлы | загрузить `H9_Cluster_v9.2.0_adminrunet_release.apk` |

APK является одним монолитным файлом, а не набором split APK. В большом поле
описания отдельно указана архитектура `arm64-v8a`.

Флаг `[OEM]` не ставится: H9 Cluster не предустановлен производителем. Флаг
`[HD]` в Мастере относится к приложениям для планшетов, а не просто к высокому
разрешению экрана. Root приложению не нужен; установка через ADB не равна
требованию root.

Если Мастер тем автоматически формирует название из нескольких полей, не
добавляйте вручную декоративные символы, BBCode, эмодзи или Unicode-значки.

## Порядок создания темы

1. Авторизуйтесь на 4PDA.
2. Повторите поиск по названию `H9 Cluster` и пакету
   `net.adminrunet.h9cluster`.
3. Откройте Мастер тем в корне «Android — Программы».
4. Заполните стандартные поля по таблице выше.
5. Загрузите иконку `h9-cluster-icon-192.png`.
6. Загрузите полноразмерный скриншот. Мастер тем сам поместит его в
   предусмотренный шаблоном блок скриншотов.
7. В большое поле «Описание программы» вставьте содержимое
   `4PDA_TOPIC_DESCRIPTION_BBCODE_RU.txt`.
8. В поле «Изменения» вставьте содержимое `4PDA_TOPIC_CHANGES_RU.txt`.
9. Загрузите APK в поле «Файлы» и дополнительно укажите прямую ссылку на тот же
   релиз GitHub в поле «Ссылка на APK».
10. Откройте предпросмотр и проверьте:
    - Мастер тем поместил картинку под спойлер;
    - APK действительно прикреплён к сообщению;
    - нет тегов `color` и `size`;
    - версия указана как `9.2.0`;
    - архитектура указана как `arm64-v8a`;
    - ссылки ведут на публичный GitHub;
    - в тексте и вложениях нет ключей подписи, паролей, приватных дампов,
      заводских APK и диагностических материалов.
11. Поля магазинов и видео оставьте пустыми: выдумывать ссылки нельзя.
12. Опубликуйте тему.
13. Если тема останется в корне раздела, попросите модератора перенести её в
    «Транспорт и Путешествия».

## Документация для пользователей и авторов тем

После публикации обновлённых файлов `docs/` в публичной ветке `main` ссылки из
готового BBCode будут вести на:

- подготовку локального компьютера и Codex;
- трёхэтапный процесс создания дизайна;
- публичный разбор создания концепта;
- публичный разбор автономного Demo APK;
- публичный разбор переноса Demo в production.

HTML-файлы не являются APK и не должны размещаться в блоке «Скачать».

## Последующие релизы

Для новой версии создайте отдельный пост и обязательно укажите:

- точную версию из Manifest;
- список изменений;
- архитектуру;
- источник APK;
- прикреплённый к сообщению рабочий APK.

Если списка изменений нет, это нужно написать прямо. Ссылка на внешний сайт не
заменяет список изменений.
