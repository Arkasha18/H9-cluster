# Поддержка

- Ошибки приложения оформляйте через
  [Issues](https://github.com/Arkasha18/H9-cluster/issues).
- Вопросы по сборке, идеи и собственные темы публикуйте в
  [Discussions](https://github.com/Arkasha18/H9-cluster/discussions).
- Уязвимости отправляйте только через
  [Private vulnerability reporting](https://github.com/Arkasha18/H9-cluster/security/advisories/new).
- По вопросам коммерческого использования: [arkasha18@gmail.com](mailto:arkasha18@gmail.com).

Проект не предоставляет консультаций по изменению заводских систем,
отключению штатных предупреждений и отправке управляющих команд автомобилю.
